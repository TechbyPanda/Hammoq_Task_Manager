# Hammoq Task Manager

## Product Overview
- **Problem:** Individuals lose track of their tasks because they're spread across Slack, notes, GitHub and Discord.
- **Goal (v1):** One central place to capture tasks and see their status at a glance.
- **Target user (v1):** Individual professionals and students tracking their own daily work. Teams come later.

## Progress
1. Task board: create, view, edit, delete, with To Do / In Progress / Done columns ✅
2. User accounts and per-user tasks: auth backend done, PR open, frontend pending 🔁
3. Pagination: API supports `page` and `limit`; the board currently loads only the first 20 tasks 🔁
4. Workspaces, roles, team invites, deadlines, real-time board ❌
5. AI assistant: summarises open tasks and suggests what to prioritise ❌
