# Hammoq Task Manager (Frontend)

## Command
1. To run on de `npm run dev`.

## Libraries
The libraries which I used in frontend.

### Tanstack
Caches API data and handles loading, errors and request cancellation. After every mutation it invalidates the task list so the UI stays in sync with the server.

### Repo
Turborepo template’s shared UI package.

### Axios
one shared API client with a base URL and timeout. 
Interceptor normalises all API errors into one shape for the UI.

### React
Component based UI
